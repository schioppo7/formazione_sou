# Commented Bash scripts

Collection of small scripts used to study Bash.

Each script has a text file with notes. The examples cover variables, parameters, exit codes, permissions, and arrays.

- `am_i_root.sh` and `am_i_root_notes.txt`
- `cleanup.sh` and `cleanup_notes.txt`
- `exit_status.sh` and `exit_status_notes.txt`
- `plain_variable_assignment.sh` and `plain_variable_assignment_notes.txt`
- `positional_parameters.sh` and `positional_parameters_notes.txt`
- `progress_bar.sh` and `progress_bar_notes.txt`
- `simple_db.sh` and `simple_db_notes.txt`
